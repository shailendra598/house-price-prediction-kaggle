# 🏠 House Price Prediction – Kaggle Competition

## 📌 Project Overview
This project focuses on predicting house sale prices using the Kaggle **House Prices – Advanced Regression Techniques** dataset. The goal was to build a complete end-to-end regression pipeline including data preprocessing, feature engineering, model training, and leaderboard submission.

---

## 🔧 Steps Performed
- Data cleaning and missing value handling
- Domain-based feature engineering
- One-Hot Encoding of categorical variables
- Log transformation of target variable (SalePrice)
- Model training using:
  - Linear Regression
  - Random Forest Regressor
- Model evaluation using R² and RMSE
- Generated Kaggle submission file

---

## 📊 Model Performance

| Model | R² Score |
|--------|----------|
| Linear Regression | 0.64 |
| Random Forest | 0.89 |

**Kaggle Public Leaderboard Score (RMSE): 0.15178**
